EF CORE 學習路線

一次一個小單元，從 SQL 學到 EF Core

先讀 EF Core 入門，了解 EF Core 是什麼、怎麼連上資料庫。接著 23 個小單元，每次只學一件事，每單元約 10–20 分鐘。

因為 LINQ 最後都會變成 SQL，每個單元都先寫出 SQL，再翻成 LINQ，最後對照 EF Core 實際送出的 SQL。SQL 不熟也沒關係，SQL 會跟著課程一起學。
